About Me

How I Approach Quality Assurance

I focus on finding issues early, writing reliable test automation, and making sure software works as expected before reaching users.

Test Automation & Frameworks

I build Selenium automation frameworks using Java, TestNG, and Maven. I use the Page Object Model (POM) to keep test logic separate from page elements, and write reusable methods so tests are easy to maintain and update. In past projects, this helped cut regression cycle times by roughly 25%.

API & Database Testing

UI testing only covers part of an application. I use Postman to test REST APIs directly—verifying status codes, headers, and response payloads. I also write SQL queries to inspect backend database tables and make sure data is stored and updated accurately.

Test Planning & Team Mentoring

Good testing starts with understanding the requirements. I write detailed test cases for functional, regression, smoke, and integration testing. In my day-to-day work, I also lead QA activities, mentor team members, and work closely with developers and business analysts during Agile sprint ceremonies.

Test Automation Framework Automation Engineering

Selenium Java Automation Framework

I independently designed and developed this reusable test automation framework from scratch using Java and Selenium WebDriver to support clean, maintainable UI automation.

Framework Architecture & Page Object Model

I structured the framework using the Page Object Model (POM) to keep page locators separate from test scripts. I created a reusable BasePage, a DriverFactory class to initialize WebDriver cleanly, utility classes for explicit waits, and configured the project using Maven.

Execution, Reporting & Test Data

I integrated TestNG for test execution and suite management, managed external test data with JSON files, and set up Extent Reports for clean execution reporting. I also added a TestNG listener that automatically captures a screenshot whenever a test fails. Source code is versioned with Git and hosted on GitHub.
